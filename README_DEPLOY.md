# Gridiron Edge Pro — publicación

Este repositorio contiene un prototipo funcional en `app.py` y `requirements.txt`. Para desplegarlo en Streamlit Community Cloud, selecciona este repositorio, rama `main`, archivo `app.py`.

**Importante:** no existe aún una conexión continua a Caliente ni un modelo predictivo entrenado y validado. El panel permite importar cuotas verificadas manualmente y calcular EV bajo probabilidades introducidas por el usuario. No publiques tokens ni contraseñas.
